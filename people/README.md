# People library

Licensed photos of public figures used in Maps and Musings reels.
One file per person: `people/<firstname-lastname>.jpg`, plus an entry in `people/index.json`:

    {"asim-munir": {"name": "Field Marshal Asim Munir", "role": "Pakistan's Army Chief", "credit": "Photo: ISPR (handout)"}}

Only real photos with a clear source (official government/ISPR/PID handouts, Wikimedia Commons CC-licensed or public-domain images). Never AI-generated or altered faces.
